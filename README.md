# 🦾 ROB-UY 2004 — Robotic Manipulation & Locomotion

> **NYU Tandon School of Engineering**  
> Introduction to robotics covering kinematics, dynamics, motion planning, and control — with hands-on labs using the Stanford Pupper v3 quadruped robot.

## 🧪 Labs Overview

| Lab | Topic | Key Concepts |
|-----|-------|--------------|
| 01 | PID Control | Proportional-Integral-Derivative control, tuning, stability |
| 02 | Forward Kinematics | Transformation matrices, Denavit-Hartenberg parameters |
| 03 | Inverse Kinematics | Jacobian methods, numerical IK solvers |
| 04 | Task Space Control | Operational space control, end-effector trajectories |
| 05 | Learning to Walk (RL) | Reinforcement learning for legged locomotion, reward shaping |

---

## 🏆 Final Project — 3-Legged Pupper Locomotion

Training a **Stanford Pupper v3** quadruped to walk with only **3 functional legs** using Reinforcement Learning — simulating a hardware failure scenario and recovering a stable gait.

👉 [See full project details](./final_project/README.md)
